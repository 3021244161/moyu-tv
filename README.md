# 摸鱼电视机 📺

双击同目录的 **摸鱼电视机.exe**。默认是 504 × 353 的无边框置顶小窗，大小随 Windows 显示缩放调整。关闭时会记住窗口位置、尺寸、置顶和声音设置。

- **选节目**　点击 YouTube、哔哩哔哩、爱奇艺、腾讯视频，或粘贴完整的视频网址。
- **听歌**　点「酷狗音乐」打开 5sing 音乐馆或酷狗主站。菜单里的《小星星》伴奏可以直接试听。播放期间回到选台页，音乐会继续。
- **看小说和文章**　首页切到「小说 · 文章」，选择书目、文章，或粘贴自己的章节和文章链接。打开正文后即可滚动阅读。原站提供上一章、下一章链接时，可在章末继续翻页。顶部书本按钮可切换阅读模式和原网页，「更多 → 阅读字号」可调整字号。
- **移动和缩放**　拖动选台页空白处移动。播放时可拖动顶部遥控条的网址区域。鼠标放在窗口内，按住 **Ctrl** 向上滚轮放大，向下滚轮缩小，每格约 10%。拖右下角也可调整大小。
- **全屏展示**　主视频播放时会自动铺满小窗并保持原始比例。按 **F11** 或点击顶部的全屏图标可铺满当前显示器；按 **Esc**、再按 **F11** 或 **Ctrl＋滚轮向下** 可恢复原来的窗口。鼠标移到上沿可唤出遥控条。「更多」中的「返回原网页」和「播放时自动铺满」可控制小窗内的展示方式。
- **高清画质**　播放器按显示器的实际 DPI 绘制，默认网页缩放为 100%。播放中点击「更多 → 视频画质」可以查看当前解码分辨率。YouTube 和哔哩哔哩可直接打开站内画质菜单，选择该视频提供的档位。
- **控制播放**　遥控条可暂停、继续、静音、切换置顶或关闭。如果平台需要先选集、登录或确认播放，请用网页自己的控件。「更多」菜单可粘贴链接、缩放网页或最小化窗口。

## 运行与构建

适用于 64 位 Windows 10/11、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。移动程序时，将 exe、同名的 exe.config 和 lib 文件夹放在一起。网页登录数据保存在当前 Windows 用户的 `%LOCALAPPDATA%\MoyuTV\WebView2`。

修改源码后，在项目目录运行以下 PowerShell 命令即可重新生成程序。项目内已随附 WebView2 SDK 所需的库。

```powershell
powershell -NoProfile -ExecutionPolicy RemoteSigned -File .\build.ps1
```
